# APP-Habit

Base propre pour l'application de dressing intelligent.

## Pipeline
1. Scan / upload vêtement
2. Détourage
3. Reconnaissance automatique précise du vêtement
4. Saison / météo / tendances
5. Moteur de recommandation de tenue
6. Fusion / virtual try-on
7. Mémoire des vêtements déjà analysés

## Principe
L'utilisateur n'a pas à corriger manuellement un type mal reconnu.
La reconnaissance doit déterminer seule le type et la catégorie.

La mémoire sert à conserver les vêtements et leurs analyses afin d'éviter de les réanalyser.
